## 饮食

### 成分

- 碳水：糖的学名，分解为葡萄糖，溶解于血液，形成血糖
- 脂肪：体脂
- 蛋白质：肌肉
- 水分
- 矿物质
- 维生素
- 膳食纤维

#### 关系

- 整体关系如下：

`<img style="display: block;margin-left: auto;margin-right: auto;" src ="https://raw.gitmirror.com/frontend-gxg/pic_bed/refs/heads/main/035.jpg">`

- 糖和蛋白质都会转化成脂肪
- 脂肪和蛋白质都会转化成糖
- 运动会先消耗糖，然后消耗脂肪，最后消耗蛋白质

### 原则

- 控料，少吃辛辣，控油，控盐，控糖
- 少吃过冷或者过热的食物
- 少吃零食饮料
- 少喝牛奶
- 适量咖啡
- 可喝白开水或者茶

## 运动

### 无氧 vs 有氧

- 无氧
  - 消耗碳水
  - 时间短，强度高
  - 主要为了塑形，训练力量
- 有氧
  - 消耗碳水，脂肪
  - 时间长，强度低
  - 主要为了减脂，锻炼体能

### 规划

- 有氧：游泳 / 跳绳
- 无氧：
  - 基础
    - 手：哑铃
    - 背：哑铃
    - 胸：俯卧撑
    - 腹：仰卧起坐、平板支撑
    - 腿：深蹲
  - 有氧配合
- 户外

### 游泳

#### 自由泳

- 打腿
  - 正常打腿
    - 陆地 -> 靠墙 -> 浮板 -> 浮板抬头 -> 无支撑
    - 蛙泳换气
    - 无节奏 -> 有节奏
  - 侧身打腿（主要用于练习侧身，头朝前 + 身体直）
    - 浮板 -> 无支撑 -> 无手
    - 无转身 -> 有转身
    - 无节奏 -> 有节奏
  - 侧打腿（主要用于练习核心，但是容易导致勾腿）
- 划手（以打腿为基础，呼吸管+鼻夹解耦换气）
  - 陆地（朝天、朝前） -> 靠墙 -> 浮板 -> 浮板抬头 -> 无支撑
  - 蛙泳换气 -> 自由泳换气
  - 单手 -> 双手
  - 抱水 + 推水：直臂划水 / 直臂推水 -> 高肘抱水（S型 / 直线）（拖肘、中线） + 推水（中线）
  - 抬臂 + 移臂：直臂移臂 -> 高肘移臂
  - 无节奏 -> 有节奏
- 换气（以划手为基础）
  - 陆地 -> 靠墙 -> 浮板 -> 无支撑
  - 无划手 -> 单手 -> 双手
- 划手交叉点：前交叉、前中交叉、中交叉、后交叉、混合交叉
- 单侧换气 vs 双侧换气：一划一换、两划一换、三划一换、四划一换
- 重踢 vs 轻踢：一划一踢（二次腿）、一划两踢（四次腿），一划三踢（六次腿）
- 学习路径
  - 打腿
    - 陆地
    - 靠墙
    - 浮板
    - 浮板抬头
    - 无支撑
  - 侧身打腿
    - 浮板
    - 无支撑
    - 无手 + 有转身
  - 划手
    - 陆地
    - 浮板 + 单侧 + 二次腿
    - 无支撑 + 单侧 + 二次腿 + 呼吸管
    - 无支撑 + 双侧 + 二次腿 + 呼吸管
  - 换气
    - 无支撑 + 双侧 + 二次腿 + 一划一换
    - 无支撑 + 双侧 + 二次腿 + 三划一换

## 睡眠

- 睡觉前两个小时慎吃
- 睡觉前一个小时慎喝
- 下午尽量不要喝咖啡、茶等提神饮料
- 睡觉前两个小时慎运动
