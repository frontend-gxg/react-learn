## 多任务

- 以终为始：以年为粒度规划 -> 以月为粒度规划 -> 以周为粒度规划 -> 以日为粒度规划
- 因此一天被划分成了多个时间不相交的大任务，一种多任务模式是大任务的多个小任务交替，一种是两个大任务交替
- 人处理任务的过程是观察 -> 思考 -> 行动，每个部分都需要占用注意力或者心智
- 比如深度思考，广度思考，或者从时间上，进行长远的思考，会让思考占用掉所有带宽或者上下文，导致没办法并行处理其他任务
- 对于只需要肌肉记忆，或者惯性思维的任务，可以让渡出空间给其他任务
- 所以早上规划，晚上复盘，把占用大脑空间的任务先完成，做好重大决策，提前把任务分派出去给到人或者agent
- 根据重要紧急程度排完优先级后，进行时间排序，按顺序排列任务（并发，不可并发），同时一个时间段最多三个小任务
- 在实际开始做时，要有当下感，不要考虑太长远，或者思考下个大任务，保证思维动作的连续性

## 饮食

### 成分

- 碳水：糖的学名，分解为葡萄糖，溶解于血液，形成血糖
- 脂肪：体脂
- 蛋白质：肌肉
- 水分
- 矿物质
- 维生素
- 膳食纤维

#### 关系

- 整体关系如下：

`<img style="display: block;margin-left: auto;margin-right: auto;" src ="https://raw.gitmirror.com/frontend-gxg/pic_bed/refs/heads/main/035.jpg">`

- 糖和蛋白质都会转化成脂肪
- 脂肪和蛋白质都会转化成糖
- 运动会先消耗糖，然后消耗脂肪，最后消耗蛋白质

### 原则

- 控料，少吃辛辣，控油，控盐，控糖
- 少吃过冷或者过热的食物
- 少吃零食饮料
- 少喝牛奶
- 适量咖啡
- 可喝白开水或者茶

## 运动

### 无氧 vs 有氧

- 无氧
  - 消耗碳水
  - 时间短，强度高
  - 主要为了塑形，训练力量
- 有氧
  - 消耗碳水，脂肪
  - 时间长，强度低
  - 主要为了减脂，锻炼体能

### 规划

- 有氧：游泳 / 跳绳
- 无氧：
  - 基础
    - 手：哑铃
    - 背：哑铃
    - 胸：俯卧撑
    - 腹：仰卧起坐、平板支撑
    - 腿：深蹲
  - 有氧配合
- 户外

### 游泳

#### 自由泳

- 打腿
  - 正常打腿
    - 陆地 -> 靠墙 -> 浮板 -> 浮板抬头 -> 无支撑
    - 蛙泳换气
    - 无节奏 -> 有节奏
  - 侧身打腿（主要用于练习侧身，头朝前 + 身体直）
    - 浮板 -> 无支撑 -> 无手
    - 无转身 -> 有转身
    - 无节奏 -> 有节奏
  - 侧打腿（主要用于练习核心，但是容易导致勾腿）
- 划手（以打腿为基础，呼吸管+鼻夹解耦换气）
  - 陆地（朝天、朝前） -> 靠墙 -> 浮板 -> 浮板抬头 -> 无支撑
  - 蛙泳换气 -> 自由泳换气
  - 单手 -> 双手
  - 抱水 + 推水：直臂划水 / 直臂推水 -> 高肘抱水（S型 / 直线）（拖肘、中线） + 推水（中线）
  - 抬臂 + 移臂：直臂移臂 -> 高肘移臂
  - 无节奏 -> 有节奏
- 换气（以划手为基础）
  - 陆地 -> 靠墙 -> 浮板 -> 无支撑
  - 无划手 -> 单手 -> 双手
- 划手交叉点：前交叉、前中交叉、中交叉、后交叉、混合交叉
- 单侧换气 vs 双侧换气：一划一换、两划一换、三划一换、四划一换
- 重踢 vs 轻踢：一划一踢（二次腿）、一划两踢（四次腿），一划三踢（六次腿）
- 学习路径
  - 打腿
    - 陆地
    - 靠墙
    - 浮板
    - 浮板抬头
    - 无支撑
  - 侧身打腿
    - 浮板
    - 无支撑
    - 无手 + 有转身
  - 划手
    - 陆地
    - 浮板 + 单侧 + 二次腿
    - 无支撑 + 单侧 + 二次腿 + 呼吸管
    - 无支撑 + 双侧 + 二次腿 + 呼吸管
  - 换气
    - 无支撑 + 双侧 + 二次腿 + 一划一换
    - 无支撑 + 双侧 + 二次腿 + 三划一换
