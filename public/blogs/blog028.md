## 输入输出记录

- 听说读写看：说写是输出、听读看是输入
- 说写可以是对内的，也可以是对外的，对内的一般算是一种记录方式，对外的一般称为输出，当然某些场景下也可以叫记录
- 输出与记录：输出与记录有交集，也有不同，比如摄影可以看成是一种记录，也可以看成是一种对内的输入方式
- 输入与输出的交互性：当你在输出的时候，也往往在输入。比如说话是一种即使交互，社交媒体上的交互可能是一种回合制交互。但是输入并不一定伴随输出，比如阅读或者听课等等
- 输入与输出的一致性：即输出的对象和平台一定要对你输入才行，这样才能形成的反馈闭环。比如你不用抖音和快手，就建议不要在这些平台上输出
- 输出的必要性：每个人输出的目的都不一样，有的是分享欲、表达欲驱动，对于我个人而言，说话更多的是为了团队合作，一个人走的快，一群人走的远，而写作或者创作更多的是为了记录记忆

## 说话

### 分类

- 日常对话
  - 闲聊，讨论
  - 一对一，一对多
  - 输出方向不确定
  - 有主题，无主题
- 演讲
  - 一对多
  - 单向输出
  - 有主题

### 道

- 在特定场景下，特定主题下，把思想转变为语言，并通过说话进行表达
- 说话需要口（眼耳）脑协调
  - 眼耳：观察输入
  - 脑：局势判断，问题思考，输出策略，语言组织
  - 口：表达输出

### 术

- 输入：
  - 临场反应要快，场面阅读和理解力要强
  - 注意倾听，注意交互
  - 理解他人的沟通意愿、语言体系、思维方式习惯、动机和原因
  - 学会观察，通过一个小点撬开关系的缺口。在整个信息喂饭的时代，留给自己一些观察的时间和训练的机会是很重要的
  - 控制自己的表达欲、倾诉欲、分享欲
  - 学会合适开口介入和打断
  - 树立自己的倾听形象和风格，不是所有内容都需要倾听
- 处理：
  - 培养好习惯，正念思维，让自身更加专注，灵活，有耐心和韧性
  - 不能自卑，自负可能让你得到不属于你的机会，但是自卑一定会让你错失本属于你的机会，所以一定要自信
  - 在原生家庭的打压下，人会习得这种习惯，并把这种心理投射到外部，导致会认为环境很容易对自己产生负面的评价，所以你需要跳出身处的环境，锻炼正念思维，在一定范围内善意的假设或者揣测别人的想法，让自己更加自信
  - 反应训练，拳击训练
  - 思想要有深度和广度的积累，记忆力要好，处理要快，让深层思考浅层化
  - 语言是思想传播的载体，在开口前，先增加思想的深度和广度，提升见识（阅历）和视野，形成价值观
  - 提升专业知识储备，同时积累基本功，以史为鉴，同时了解时事
  - 多看不同场景，不同主题的演说视频，熟悉表达策略和组织框架
  - 多实战，多思考，多表达，提升思考速度和表达精确度，思维敏捷，表达简洁
  - 先思后说，不要瞎说
  - 在某个领域有名，并只针对该领域发表观点，避免在其他不擅长的领域发表看法
  - 情绪 -> 事实 -> 目的，说话少侧重情绪，多侧重事实，引导达成共识，最终达成目的
  - 过程或者结果的权衡，在工作场景中，直接抛出答案应该是最简单的，但是当今社会信息扁平化后，人很容易获取到某件事情的答案或者观点，信息变得快餐化，答案变得廉价，思维变得僵化，所以酌情使用探索或者开放结尾的方式探讨也是不错的选择
  - 简洁，自顶而下
  - 语言通俗化，框架简单化，减少脏话，口头禅，减少成语，歇后语，诗词，文言文等
  - 对不熟悉的工具，比如肢体语言，道具等等，谨慎使用
  - 培养自己的品味和风格
  - 成就他人，成就自己
  - 学会赞美他人，不要背后诋毁别人，公众场合赞美 > 当面赞美 > 背后赞美，具体赞美
  - 点评：赞美 -> 建议 -> 鼓励
  - 减少说服感和说教感
  - 学会放下面子和自尊
  - 弱化个人感受，强调事实
  - 学会一本正经的胡说八道
  - 不说脏字和脏话，减少口头禅
  - 使用上下文小和熵减的说话方式：先说结论，后再展开，总分结构，学会向上分类归纳抽象提炼推演引申，使用系统性和结构性思维。使用平行顺序 > 认知顺序 > 分析顺序 > 时间顺序 > 历史顺序
  - 朗读跟读背诵
  - 复盘总结当前的事情或者重要的事情
  - 分享时事和故事，如何吸引人，让自己成为有故事的人
  - 写作：写作是慢速的表达，表达是快速的写作
  - 看听别人的演讲
  - 积累素材：时事、观点、故事
  - 故事：
    - 冲突 -> 过程 -> 结果
    - 篇幅、情节、细节、悬念（问题、好奇心、分寸感）、画面感（没用过，少用过）、情感、提炼、升华
  - 问题：引发思考，传达理念
- 输出：
  - 发声练习，注意语音语调，语速节奏，适当停顿
  - 腹式呼吸：胸腔 -> 声带 -> 口腔
  - 耳语发生训练
  - 联系：ci和he
  - 抑扬顿挫：声音不要平的，要带有感情
  - 停顿：也要会快速的说话
  - 吐字清晰
  - 呼吸控制
  - 参照物

### 演讲

- 演讲是在一定限制下，通过语言作为载体，把你对某个主题的思想，传播给听众的过程
- 演讲需要关注效果，演讲前需要关注受众的画像，演讲中需要关注受众的反馈
- 大部分人都不是天生的演说家，所以在没有能对演讲内容非常熟练之前，请提前准备好演讲稿，并熟读至少两遍，保证掌握了整体脉络，内容重点，以及前后的承接
- 注意限制：主题、目的、受众、场地、时长
- 主题
- 目的
  - 关注演讲的层次：是浅层的还是深层的，是否要改变观众的思维方式，比如知识、信仰和感受
- 紧张
  - 期望
  - 准备
- 观众
  - 普遍特征：性别、年龄、职位、收入、意愿
  - 主题目的相关的特征：需求、关心
- 个性化
  - 观众特征
  - 演讲者特征
  - 主题
  - 不是自言自语，不是博人眼球，而是量身定制
- 形象
  - 站姿：站定3s后开始演讲，重心要均匀稳定的分配在两腿上，不能来回摇晃，目光要朝向观众
  - 移动：不能太快，不能太频繁，目光要朝向观众
  - 眼神：不能看天花板或者地板，把观众区域划分为4到6块，每块停留5到15秒，看观众眉心
  - 面部：微笑
  - 手势：开放V字，切勿封闭，开合有度
- 前置
  - 身份
  - 环境
- 开头
  - 方式
    - 直接表达目的
    - 讲一个相关的事实和故事
- 准备
  - 预演彩排
  - 练习开场白
  - 内容要比实际时长多30%，保证上台后能灵活调整
  - 提前去场地
- 演讲稿
  - 服务目的主题，以终为始
  - 总分
  - 框架大纲 -> 大致内容 -> 细节加法 -> 润色减法
  - 观点一定要简单简短，并且补充例子
  - 试讲 / 演练
    - 对着空气讲
    - 找人讲
    - 在现场或者模拟现场讲
    - 大脑模拟
    - 录像复盘
  - 重复观点：开场、中间、结尾
  - 时间控制：计时、对讲稿不同模块有时间概念
- 开场前
  - 提前和观众沟通，比如问问他们想听什么内容，对演讲有什么建议
- 开场
  - 面对观众，先停顿一下
  - 提问，把压力转移给观众，问一些简单、封闭式的问题，然后再问复杂，开放式的问题
- 中间
  - 对积极的观众要拉拢
  - 回答问题：反问、转移、稍后回答
- 进阶
  - 吸引力：讲笑话，吹牛逼，装逼
  - 跟随力：讲故事，类比，提问
  - 说服力：逻辑，数据
  - 共鸣：情感，激情，境界
- 结尾
